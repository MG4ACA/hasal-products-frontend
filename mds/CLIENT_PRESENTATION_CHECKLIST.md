## ❓ Anticipated Questions & Answers

**Q: How do returns work?**  
A: Returns are processed as negative line items in the same invoice, with tracking for reason (damaged, excess, etc.) and disposition (back to stock or dispose). This keeps all transaction history in one place.

**Q: Why don't employees (sales refs/drivers) get login access?**  
A: Based on your workflow, employees are tracked for reference only (who collected orders, who drove). Only office staff (Admin/Cashier) need to enter data into the system. This keeps the system simple and secure.

**Q: How are batch numbers generated?**  
A: The system automatically generates batch numbers in the format RM-MAT001-20251218-001 (raw material code + date + sequence) when you receive purchase orders. No manual entry needed.

**Q: How does vehicle-to-route assignment work?**  
A: Admins assign vehicles to routes dynamically. The system tracks assignment history so you can see which vehicle served which route and when. One vehicle per route at a time.

**Q: What payment methods are supported?**  
A: Cash, Credit, and Check. For checks, the system tracks check number, check date, and clearance date to help you manage pending checks.

**Q: Can we add more features later?**  
A: Yes, but those would be separate from this scope and cost. The system is designed to be expandable.

**Q: What if we need changes during development?**  
A: Minor tweaks are fine. Major changes would require a change order and may affect timeline/cost.

**Q: What happens after 30 days support?**  
A: We can arrange a monthly support contract. Typically 10-15% of project cost annually.

**Q: Do you provide hosting?**  
A: Not included in this quote. We can deploy to your server or help you set up cloud hosting (additional cost).

**Q: Can drivers add orders on mobile?**  
A: Not in v1.0 (see "Future Enhancements" in requirements). We can add this in Phase 2 of the project.

**Q: What if the system goes down?**  
A: During 30-day support, we fix issues immediately. After that, response time depends on support contract.

**Q: Can we get a demo before paying?**  
A: This is custom development, not an off-the-shelf product. We'll show progress demos at milestones.

**Q: Can we pay in installments different from proposed?**  
A: Payment schedule is flexible - we can discuss what works for your cash flow.
