## 1. Executive Summary

This document outlines the features and implementation status of the Hasal Products POS and Inventory Management System. The system defines a complete lifecycle for a spices manufacturing and distribution business, handling everything from raw material procurement to retail sales.

## 2. Implemented Modules & Features

### 2.1 Product & Inventory Management

- **Product Definition:**
  - Creation of "Base Products" (e.g., Chili Powder).
  - Management of multiple **SKUs** per product (e.g., 50g, 100g, 1kg packets).
  - Categorization of products.
- **Stock Management:**
  - Real-time stock tracking for each SKU.
  - **Automated Stock Value Calculation:** Shows the total value of current inventory based on weighted average cost.
  - Profit Margin indicators (Green/Yellow/Red tags) on the product list.

### 2.2 Supply Chain (Purchase Orders)

- **Supplier Management:**
  - Manage supplier details and credit balances.
  - Track payment history.
- **Purchase Order (PO) Workflow:**
  - **Create PO:** Select supplier and raw materials.
  - **Receive Goods (GRN):** Support for partial or full receipts.
  - **Batch Tracking:** Every received item creates a unique batch number for traceability (FIFO).
  - **Integrated Payments:** Record payments directly upon receiving goods.
- **Returns to Supplier:**
  - Handle returns for "Excess Stock" or "Quality Issues".
  - Options to return to stock or dispose.

### 2.3 Manufacturing (Production)

- **Recipe Management:**
  - **Bill of Materials (BOM):** Define raw materials required for each product.
  - **Versioning:** Track changes to recipes over time (v1, v2, etc.). Only the active version is used for production.
- **Production Workflow:**
  - **Production Runs:** Plan production batches for specific dates.
  - **Raw Material Consumption:** Automatically deducts raw materials using **FIFO (First-In-First-Out)** logic to ensure older stock is used first.
  - **Yield Analysis:** Compare "Expected Output" vs "Actual Output".
  - **Efficiency Tracking:** System calculates production efficiency and waste.
    - Green: ≥95% Efficiency
    - Red: <75% Efficiency

### 2.4 Sales & Distribution

- **Route & Outlet Management:**
  - Manage delivery routes and assign outlets.
  - Track outlet credit limits and outstanding balances.
- **Invoicing (POS):**
  - Select Outlet -> Add Products -> Calculate Total.
  - **Real-time Stock Validation:** Prevents selling out-of-stock items.
  - **Credit Limit Enforcement:**
    - **Warning** at 80% utilization.
    - **Block** at 100% (requires Admin override for Cashiers).
- **Payment & Cheque Management:**
  - Accept Cash, Cheque, or Credit.
  - **Cheque Bounce Handling:** Automated process to reverse payments and update outlet debt if a cheque bounces.
- **Sales Returns:**
  - Validate returns against original invoice history.
  - **Policy Enforcement:** Checks for return window (e.g., 7 days for damaged goods).

### 2.5 Reporting & Analytics

- **Dashboard:** Real-time overview of sales and production.
- **Profit Analysis:** Detailed breakdown of revenue vs. COGS (Cost of Goods Sold).
- **Waste Cost Report:** Paradox of waste generated during production.
- **Production Efficiency Report:** Track performance of manufacturing teams.

## 3. Technical Implementation Details

### 3.1 Backend Architecture (Node.js/Express)

- **MVC Pattern:** Organized into Models, Views (API verification), and Controllers.
- **Transaction Safety:** All financial and inventory updates are wrapped in database transactions to ensure data integrity.
- **Security:** Role-based access control (Admin, Cashier, etc.).

### 3.2 Database (MySQL)

- **Complex Relations:**
  - Self-referential batch tracking for returns.
  - Virtual fields for dynamic calculations (e.g., `paid_amount` on invoices).
- **Migrations:** Managed schema updates (e.g., adding return validation fields).

### 3.3 Frontend (Vue.js 3)

- **Responsive UI:** Built with PrimeVue components.
- **State Management:** Pinia stores for efficient data handling.
- **Dynamic Navigation:** specific Reports section and updated sidebars.
